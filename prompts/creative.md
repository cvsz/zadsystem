# Creative Prompt - Ad Copy Generator

## ภารกิจ
สร้าง ad copy สำหรับ {product} ด้วย angle {angle}

## ข้อมูลผลิตภัณฑ์

- Product: {product}
- Target Audience: {audience}
- Platform: {platform}
- Angle: {angle}
- Tone: {tone}

## สิ่งที่ต้องสร้าง

1. **Hook Lines** (3 variations)
   - ดึงดูดความสนใจใน 3 วินาทีแรก
   - ใช้ pain point หรือ benefit

2. **Body Copy** (2 versions)
   - Version A: Short & Punchy
   - Version B: Detailed & Educational

3. **CTA Options** (3 variations)
   - Direct purchase
   - Learn more
   - Conversation starter

4. **Visual Recommendations**
   - Image/video concepts
   - Key visual elements
   - Color suggestions

## Guidelines

- ใช้ภาษาที่เป็นธรรมชาติ
- หลีกเลี่ยงคำที่ดู salesy เกินไป
- เน้น benefit มากกว่า feature
- มี social proof ถ้าเป็นไปได้
- สร้าง urgency/scarcity แบบไม่ fake

## Example Output

```
🎯 Hook: "ผิวใสออร่าใน 7 วัน ไม่ต้องฉีดเมโส!"

📝 Body:
เซรั่มวิตามินซีสูตรใหม่ล่าสุด
✅ เห็นผลจริงใน 7 วัน
✅ ปลอดภัย แม้ผิวแพ้ง่าย
✅ ผ่านการทดสอบทางคลินิก

👉 CTA: "ทักแชทรับส่วนลด 20% วันนี้เท่านั้น!"

🎨 Visual: Before/After 7 days, flatlay with vitamin C oranges
```
