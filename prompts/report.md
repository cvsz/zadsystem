# Report Prompt - Executive Summary Builder

## ภารกิจ
สร้างรายงานผู้บริหารจากข้อมูล competitive analysis

## ข้อมูลที่มี

- Brand: {brand}
- Competitors Analyzed: {competitors}
- Time Period: {period}
- Total Ads Reviewed: {count}

## โครงสร้างรายงาน

### 1. Executive Summary (1 ย่อหน้า)
- ภาพรวมสำคัญ
- Key findings
- Top recommendation

### 2. Market Overview
- Competitive landscape
- Market trends
- Share of voice (ถ้ามี)

### 3. Winning Ads Analysis
- Common patterns
- Top performing angles
- Best practices

### 4. Gap Analysis
- Blue ocean opportunities
- Red ocean warnings
- White space to exploit

### 5. Strategic Recommendations
- Short-term actions (1-2 weeks)
- Mid-term plans (1-2 months)
- Long-term strategy (3+ months)

### 6. Creative Direction
- Recommended angles
- Messaging framework
- Visual direction

### 7. Next Steps
- Action items
- Owners
- Timeline

## Tone

- Professional but accessible
- Data-driven insights
- Actionable recommendations
- Clear prioritization
