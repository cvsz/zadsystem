# Spy Prompt - Ad Library Analysis

## ภารกิจ
วิเคราะห์โฆษณาของ {brand} จาก Meta Ad Library

## สิ่งที่ต้องทำ

1. **รวบรวมข้อมูล**
   - จำนวนโฆษณาทั้งหมด
   - ช่วงเวลาที่รันโฆษณา
   - Platforms ที่ใช้

2. **วิเคราะห์ Content**
   - Hooks ที่ใช้บ่อย
   - Angles การขาย
   - CTAs
   - Visual styles

3. **หา Patterns**
   - โฆษณาแบบไหนรันนานที่สุด (แสดงว่าได้ผล)
   - ความถี่ในการโพสต์
   - Seasonal campaigns

## Output Format

```markdown
## Brand: {brand}

### Overview
- Total Ads: X
- Active Period: ...
- Top Platforms: ...

### Content Analysis
- Top Hooks: ...
- Common Angles: ...
- CTAs Used: ...

### Key Insights
1. ...
2. ...

### Recommendations
- ควรทำ: ...
- ควรเลี่ยง: ...
```
